# 安全与使用边界

## 先理解自动耗电

自动耗电不是仅限制充电上限：它尝试切断适配器，并通过自适应纯 CPU 工作线程主动耗电。可能增加温度、风扇噪声、循环和任务干扰；不承诺改善健康度。默认关闭，启动后不自动恢复上次开启状态。不要在无人值守、散热受阻、低电量或关键任务期间启用。

## 负载预算与热保护

- 最多使用 `min(4, max(1, 逻辑核心数 / 2))` 个普通优先级以下的工作线程，不绑定特定核心、不调整频率、电压或风扇。保留核心数量不等于物理隔离，调度仍由 macOS 决定。
- 以 20 毫秒为目标时间片，计算小批量、数据相关的标量算术；每线程目标占空比最高 85%，每次安全传感器采样只增加最多 0.25 个核心的总计算预算，降载立即生效。时间片不是实时调度保证。
- 默认 CPU 温度上限为 75°C；兼容旧配置，但实际停止点始终取用户设置与 75°C 中较低者，并在接近停止点的最后 15°C 内渐进降载。此值是应用预算，不是 Apple 硬件安全额定值，也不是电池温度。
- 系统热状态为 fair 时最多保留单线程 25% 目标占空比；serious、critical 或未知状态停止。工作线程每个时间片独立检查系统热状态，不仅依赖界面采样。CPU 温度仍随普通传感器采样更新，不是实时监测。
- 不添加 GPU 工作、大内存分配、网络流量或循环磁盘写入；正常监测、配置保存和硬件助手仍有少量资源开销。不承诺不会触发系统交换或其他间接资源使用。
- 不绕过现有低电量停止点，不实现放到 0% 或强制过放，也不绕过系统保护。加快放电不等于可以精准地只损伤电池；无法保证其他硬件零损耗，实际耗电速率与热影响必须实机测量。

## 权限与通信

界面、传感器读取和负载运行于普通用户权限。需要硬件写入时，App 使用系统管理员授权启动内置 `BatteryHardware`。不会修改 sudoers，不安装新的常驻 LaunchDaemon，不暴露网络控制服务。

助手校验父进程 PID、UID、启动身份与所在 App 的可执行文件路径；只接受固定动作，不允许传入任意 shell 或 SMC 键。通信使用随机会话令牌及属主权限为 0600 的 Unix socket。路径和进程检查不是代码签名信任链的替代：请仅运行自己信任、没有被替换的构建，不要让不可信进程修改 App 包。当前并非经审计、正式签名的 SMAppService 特权助手方案。

## 生命周期与恢复

- App 每 2 秒向助手发送心跳；助手约每秒检查父进程，心跳失联超过 30 秒会尝试恢复适配器并退出。
- 普通退出停止 CPU 负载、释放防睡眠断言并请求助手恢复适配器；失败时提示用户。
- CPU 工作线程超过 12 秒未续租会停止，租约使用不受系统时间调整影响的单调时钟；防睡眠断言亦有短时超时。
- 温度缺失时不启动 CPU 耗电。过温进入冷却，低电量停止循环。

这些是尽力恢复，不是硬件级保证：系统挂起、断电、硬件故障、同时杀死助手或多工具争用，都可能使恢复失败。不要通过强制退出代替正常退出；异常后请检查电源状态。恢复供电不代表系统一定立即充电。

## 旧服务迁移

仅迁移本项目的 `/Library/LaunchDaemons/com.local.battery-service.plist`。检查标签、所有者及权限；备份到 `/Library/Application Support/BatteryBar/LegacyBackup/<时间>/` 后，停止旧任务并移动旧 plist，避免下次开机重复启动。不会替用户停止其他 Homebrew 电池工具。

旧配置可能从 `/Library/Application Support/BatteryService/config.json` 导入。仓库不提供该个人配置，也不包含旧 HTTP 服务；请勿同时运行旧服务和新 App 的硬件控制。

## 隐私与问题报告

当前第一方代码不含遥测上传逻辑。不要在公开 Issue 上传未脱敏的日志或配置。涉及权限提升、令牌泄露或任意命令执行的问题，请先通过 GitHub 私密漏洞报告（若仓库启用）联系维护者；不可用时，先发不含漏洞细节的 Issue 请求私下联系渠道。

## 本地电量历史与预测

2.3 默认在 App 运行时复用现有快照记录时间、电量、健康度、循环数、供电/充电状态、CPU 温度及耗电开关。不记录序列号，不上传；SQLite 文件权限 0600，保存约 365 天，支持 CSV 导出和确认清空。CSV 可能包含使用时间和习惯，请勿公开未脱敏的记录。清空为逻辑删除，不声称取证级安全擦除。统计功能添加少量正常存储 IO，不制造磁盘压力负载。

健康度预测仅为未验证的长期趋势情景，不表示何时一定损坏、不用于保修判断，不指导主动损耗。整数容量的校准、缺失观测、换电池、温度和未来使用均可使结果失效；数据不足、持平或不稳定时必须不显示预测日期。
